# Cross-IDE Factory Implementation Status

## Implemented in this change

- Opt-in enrollment states for existing projects.
- Unmanaged repositories remain outside compliance scope.
- Portable project state and task records.
- Cross-IDE checkpoint and resume commands.
- Advisory/proposal/inspection/execution routing contract.
- Cursor, Claude, generic agent, and Antigravity adapter templates.
- Scope-lock and agent-policy templates.
- Agent model/effort run-receipt schema with explicit verification levels.
- Deterministic structural compliance.
- Self-test and managed-project workflow templates.

## Deliberately deferred

- Direct provider runners for verified model execution.
- Fleet repository discovery and scheduled audits.
- Central documentation mirroring.
- Automatic Git worktree creation.
- Cost and token accounting.
- Automatic rule migration pull requests.

These later capabilities should build on the enrollment, portable state, and receipt contracts introduced here.
